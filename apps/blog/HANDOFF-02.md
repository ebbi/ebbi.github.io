## Frozen decisions made in this chat

- The WordPress.com Public API (`public-api.wordpress.com/rest/v1.1/...`) returns `content` and `title` as direct strings, unlike the standard WP REST API which wraps them in `{ rendered: "..." }`. The parser is designed to handle both string and object formats gracefully.
- HTML parsing relies on native Node.js regex. It successfully extracts paragraphs, headings, images, figures, blockquotes, lists, tables, dividers, and embeds. Complex nested Gutenberg block comments are currently stripped, which is acceptable for the pilot phase.
