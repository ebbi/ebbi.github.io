# Milestone 05a: Feeds & Search Index

## Objective

Create the offline Node.js tooling to generate a lightweight, client-side searchable index and a JSON feed from the parsed `posts.json` data. This ensures fast, framework-free fuzzy search without requiring a backend database.

## Files to Create

1. `apps/blog/tools/generate-index.js`
2. `apps/blog/assets/data/search-index.json` (Generated output)
3. `apps/blog/assets/data/feed.json` (Generated output)

## Files to Modify

- None.

## Files I will NOT touch

- Any files outside `apps/blog/`.
- `apps/blog/assets/js/` (Frontend JS is not touched yet).
- `apps/blog/tools/parser.js` or `apps/blog/tools/fetcher.js` (Read-only access).

## Hard Constraints (from LOCKED_DECISIONS.txt)

- **Node 20 LTS**: Use native `fs`, `path`. No external npm dependencies.
- **Index Schema**: The `search-index.json` must be a flat array of objects containing only: `slug`, `title`, `date`, `lang`, `excerpt` (first 150 chars of text blocks), and `tags` (empty array for now, reserved for future).
- **Feed Schema**: The `feed.json` must contain the 10 most recent posts (sorted by date descending) with `slug`, `title`, `date`, `lang`, and `excerpt`.
- **Performance**: The script must read `apps/blog/assets/data/posts.json`, process it, and write the two new JSON files in under 1 second.

## Test Checklist

1. **File Tree Check**:
   - Run: `ls apps/blog/tools/generate-index.js`
2. **Execution Check**:
   - Run from workspace root: `node apps/blog/tools/generate-index.js`
   - It must output: "✅ Successfully generated search-index.json and feed.json".
3. **Schema Validation**:
   - Open `apps/blog/assets/data/search-index.json`. Verify it is an array of objects with the exact keys: `slug`, `title`, `date`, `lang`, `excerpt`, `tags`.
   - Verify `excerpt` contains plain text (no HTML tags) and is truncated to ~150 characters.
   - Open `apps/blog/assets/data/feed.json`. Verify it contains exactly 10 posts (or fewer if the total is < 10), sorted by date descending.
