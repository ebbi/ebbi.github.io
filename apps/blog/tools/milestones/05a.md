# Milestone 05a: Feeds & Search Index (Backend Only)

## Objective

Create the offline Node.js tooling to generate a lightweight JSON feed from the parsed `posts.json` data.
NOTE: We are discarding the frontend Search UI (05b) for now. This milestone is STRICTLY offline Node.js tooling.

## Files to Create

1. `apps/blog/tools/generate-index.js`
2. `apps/blog/assets/data/feed.json` (Generated output)

## Files to Modify

- None.

## Files I will NOT touch

- Any files outside `apps/blog/`.
- `apps/blog/assets/js/` (NO FRONTEND JS IN THIS MILESTONE).
- `apps/blog/tools/parser.js` or `apps/blog/tools/fetcher.js` (Read-only access).

## Hard Constraints (from LOCKED_DECISIONS.txt)

- **Node 20 LTS**: Use native `fs`, `path`. No external npm dependencies.
- **Feed Schema**: The `feed.json` must contain the 10 most recent posts (sorted by date descending) with `slug`, `title`, `date`, `lang`, and `excerpt` (first 150 chars of text blocks).
- **Execution**: The script must read `apps/blog/assets/data/posts.json`, process it, and write `feed.json`.

## Test Checklist

1. **File Tree Check**: `ls apps/blog/tools/generate-index.js`
2. **Execution Check**: `node apps/blog/tools/generate-index.js`
3. **Schema Validation**: Open `feed.json`. Verify it contains exactly 10 posts, sorted by date descending, with plain text excerpts (no HTML).
