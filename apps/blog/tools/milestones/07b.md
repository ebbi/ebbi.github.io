# Milestone 07b: Theme toggle (light / dark / auto)

## Scope fence (read first)

This milestone adds a THEME control (light / dark / auto) to the app's
Settings panel — the existing 07 drawer (`#app-panel`) — and the logic that
applies it. It touches `index.html` (add the control to the drawer),
`assets/css/style.css` (day token block + any additive control classes; the
`night` token block already exists), one new JS module or an addition to
`shell.js`, and the ROADMAP/CURRENT pointer. It does NOT touch the extraction
seam (`tools/import-post.js`, frozen through D-Tool-29), any
`content/**/*.json`, `feed.json`, `renderer.js` block mappings, router.js,
app.js route/render logic, TTS (that is the TTS milestone), or font selection
(that is 07c). It must NOT change the meaning of any existing 08/09/10b/B1
class — themes re-point tokens only.

## Objective

When this milestone is done:

- the drawer contains a Theme control offering **Light**, **Dark**, and
  **Auto** (a native `<select>` or a 3-state button group, with an
  accessible name),
- selecting a theme sets `document.documentElement`'s `data-theme` to
  `day` or `night` (Auto follows `prefers-color-scheme`),
- the choice **persists** across reloads (localStorage) and is applied before
  first paint (no flash of the wrong theme),
- the existing `html[data-theme="night"]` token block drives dark mode and a
  matching `html[data-theme="day"]` (or default `:root`) drives light mode,
- and the control does not regress RTL, focus visibility, or the 07 drawer
  behaviour.

## Decisions frozen for this milestone

- T-1: The theme control lives in the 07 drawer (#app-panel) — the "Settings
  panel". No new panel is introduced.
- T-2: `data-theme` values are `day` and `night` (matching the pre-existing
  `html[data-theme="night"]` block). Auto resolves to day or night via
  `prefers-color-scheme` and re-resolves when the OS preference changes.
- T-3: Persistence via localStorage under ONE key; the resolved theme is
  applied in a small inline head script (or theme.js loaded in <head>) BEFORE
  first paint to avoid a flash. If an inline head script is used, it must set
  `data-theme` only and is the single source of that early application.
- T-4: Themes re-point CSS tokens ONLY; no component class changes meaning.
- T-5: Guarded init in app.js (theme.js optional; app must not break if it is
  absent).
