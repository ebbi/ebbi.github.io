# Milestone 10b: List item as collapsible panel

## Scope fence (read first)

This milestone changes the LIST VIEW only: each list item becomes a
collapsible panel whose title toggles the excerpt, plus a "read full post"
link. It touches `assets/js/app.js` (renderList) and `assets/css/style.css`
(additive list-item classes) and may touch `assets/js/router.js` ONLY if a
new event wiring requires it (preferred: no router change — the existing
`#/<lang>/post/<slug>` link already routes). It does NOT touch the
extraction seam (`tools/import-post.js`), any `content/**/*.json`,
`feed.json` (generated), `parser.js`, `fetcher.js`, `generate-index.js`,
`hash-state.js`, `renderer.js`, or `test-integrity.js`. It REVISITS 08's
list presentation (overlaps C1b-18's series ordering, which stays as-is).
L-010 (feed-excerpt HTML leak for part-22) may be addressed here OR
deferred to its own milestone; decide at scope confirmation.

## Objective

When this milestone is done, the home/list view renders each entry as a
mobile-first, keyboard-accessible collapsible panel: the title is a toggle
button that reveals/hides that item's excerpt, and a separate "read full
post" link navigates to the post. The series ordering from C1b-18 (reading
order 1 -> 23, then non-series) is preserved. No other view changes.

## Interfaces (mandatory — a milestone without these is not ready)

### Modified: apps/blog/assets/js/app.js

    renderList(route): the per-item markup changes from the current
      <article class="post-list-item">
        <a class="post-list-item__title" href="#/<lang>/post/<slug>">...</a>
        <p class="post-list-item__meta">...</p>
        <p class="post-list-item__excerpt">...</p>
      </article>
    to a collapsible panel. Proposed shape (finalize at implementation):
      <article class="post-list-item">
        <button class="post-list-item__toggle" aria-expanded="false"
                aria-controls="excerpt-<slug>">
          <span class="post-list-item__title-text">...title...</span>
        </button>
        <p class="post-list-item__meta">...</p>
        <div class="post-list-item__panel" id="excerpt-<slug>" hidden>
          <p class="post-list-item__excerpt">...excerpt...</p>
          <a class="post-list-item__read" href="#/<lang>/post/<slug>">
            Read full post</a>
        </div>
      </article>
    - The series ordering logic (partition by integer seriesOrder; series
      1 -> 23 first, then non-series in feed date-desc order) is UNCHANGED.
    - One delegated click listener on the list container toggles
      aria-expanded + the `hidden` attribute of the controlled panel.
      Keyboard: the toggle is a real <button> (Enter/Space activate it).

### Modified: apps/blog/assets/css/style.css

    ONE additive "Milestone 10b" block, new classes only:
      .post-list-item__toggle, .post-list-item__title-text,
      .post-list-item__panel, .post-list-item__read
    Reuses existing tokens; logical properties only; RTL-safe. Edits NO
    existing block; existing 08/09 list classes stay valid.
