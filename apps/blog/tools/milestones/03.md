# Milestone 03: Frontend Renderer

## Objective

Build the client-side Vanilla JS rendering engine. This module will take the standardized Block JSON (generated by the parser) and dynamically construct the DOM elements for the blog post. It must be lightweight, framework-free, and ready to handle RTL/LTR typography.

## Files to Create

1. `zabon/apps/blog/assets/js/renderer.js`

## Files to Modify

- None.

## Files I will NOT touch

- Any files outside `zabon/apps/blog/`.
- `zabon/apps/blog/tools/` (Node.js tooling is not touched).
- `zabon/apps/blog/index.html` (HTML shell is not touched yet).

## Hard Constraints (from LOCKED_DECISIONS.txt)

- **Vanilla JS only**: No frameworks, no build steps. Pure DOM manipulation (`document.createElement`, `classList`, etc.).
- **Block Mapping**: Must have a dedicated render function for every block type defined in LOCKED_DECISIONS.txt (paragraph, heading, image, etc.).
- **Sanitization**: When inserting HTML content (e.g., inside a paragraph block), use `DOMParser` or safe innerHTML practices to prevent XSS, though content is trusted from our own build pipeline.
- **Extensibility**: The renderer should be exported as a module or an object (e.g., `window.BlogRenderer.render(blocks)`) so the router/app can call it.
