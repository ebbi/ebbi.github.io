## Risks / notes
- Do NOT use the IDE Apply mechanism for tools/*.md or tools/*.txt: it has been
  observed to rewrite `*` -> `_` silently. Use one verified terminal command per
  edit (sed -i on a single line, or a Node script), then verify with grep/cat -A.
- Do NOT batch multiple shell commands in one Run action: VS Code's run-this-
  block has dropped/duplicated commands. One command, verify, then the next.
- Any census drift on the three migrated slugs means the seam change regressed
  them: STOP and investigate before writing anything.
- If the chosen slug needs a new seam rule, that is a SEPARATE, narrow
  extension of the D-Tool-9 freeze (as D-Tool-18 and D-Tool-19 were), locked
  as its own decision before the slug migrates.
