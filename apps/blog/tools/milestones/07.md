# Milestone 07: App Shell & Toolbars

## Scope fence (read first)

07 is a **structural chrome** milestone. It converts the page into a
common responsive mobile-first app shell: a fixed top toolbar, a fixed
bottom toolbar, and a main content area inset so the bars never cover
content. It adds a hamburger button and a side-panel (drawer) shell, and
**moves** the existing 06b language switcher (`#lang-nav`) into that
panel.

07 does NOT: add theme/light-dark logic (that is 07b); add font
selection or font assets (that is 07c); implement text-to-speech (TTS is
a later milestone; 07 ships its transport buttons inert); change routing,
block rendering, or data files; translate content; or introduce a
desktop persistent rail (deferred to a follow-up milestone).

## Objective

When this is done:

- the app has a fixed top toolbar (title links to home) and a fixed
  bottom toolbar, both mobile-first, logical-property, RTL-safe, and
  respecting phone safe-area insets,
- the main content area is inset by the top and bottom toolbars so no
  content is ever hidden behind them,
- a hamburger button in the top toolbar opens a side-panel drawer
  (open/close, ESC, backdrop click, focus handling, `aria-*`) that
  contains the language switcher moved from the header,
- the bottom toolbar contains Play / Pause / Stop transport buttons,
  rendered **disabled/inert** (no behavior; TTS lands later), and
- the drawer works at all widths (one overlay panel); no desktop rail.

## Decisions frozen for this milestone

- **S-1 Desktop treatment.** The drawer is an overlay panel at ALL
  widths. No persistent desktop rail. A left-rail desktop treatment is
  deferred to a follow-up milestone (07d, authored later).
- **S-2 Theme.** No light/dark/auto logic in 07. The theme toggle is
  07b. 07 must not set `data-theme`.
- **S-3 Fonts.** No font selection or font assets in 07. The
  modern/traditional selector is 07c; committed webfonts are deferred to
  a decision/media milestone (system stacks first).
- **S-4 TTS.** Transport buttons (Play/Pause/Stop) are present but
  `disabled` and inert. No audio, no Web Speech API, no behavior. TTS is
  a reserved later milestone and consumes these buttons.
- **S-5 Language switcher reparented, not rewritten.** `#lang-nav`
  (06b native `<select>` + flag) moves into the drawer. Its id, the
  `#lang-select` id, and BlogNav's public surface are unchanged. nav.js
  is touched only to make the DOM lookup robust to the new location.
- **S-6 ROADMAP edit.** 07 modifies ROADMAP.md to record the split (07,
  07b, 07c, TTS reserved) and the removal of "07 Footer & Global UI."
  ROADMAP reordering is expected (W1F-D1); the edit is declared here and
  recorded as a frozen decision in this handoff.
- **S-7 Forward edit.** This milestone file was first authored at 06b's
  close and committed in 8cc3298. This is a superseding rewrite. No
  history rewrite (W1F-D3); recorded in HANDOFF-07.
- **S-8 Shell a11y.** Hamburger is a `<button>` with
  `aria-expanded`/`aria-controls`; the panel uses `aria-hidden`
  toggling; ESC closes; backdrop click closes; focus moves into the
  panel on open and returns to the hamburger on close. No focus trap
  implementation in 07 beyond ensuring the panel is reachable and
  escapable.
