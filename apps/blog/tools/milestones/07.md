# Milestone 07: Footer & Global UI

## Scope fence (read first)

07 is a **global-chrome** milestone. It finalizes the page footer and any
site-wide UI that is not the header (06/06b) and not the content views
(list/post, later milestones). It does NOT touch routing, block
rendering, data files, or the language switcher's behavior. No new data
contracts. Offline fallback / caching is explicitly OUT of scope (see
ROADMAP.md `13b`; a fetch-failure UI belongs with the caching layer, not
here).

## Objective

When this is done:

- the footer is structured markup (not a bare `<p>`), mobile-first, with
  logical-property layout so it is RTL-safe,
- the footer holds any global links the app commits to (at minimum a
  language-agnostic home link), with a single source for that chrome, and
- the footer copy and links are recorded under the translation review
  gate.
