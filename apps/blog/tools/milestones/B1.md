# Milestone B1: Renderer remaining block types

## Scope fence (read first)

This milestone is RENDERER-ONLY. It adds four new `case`s to
`renderBlock()` in `assets/js/renderer.js` (pullquote, resourceList, callout,
attachment) and one additive, new-class-only "Milestone B1" block to
`assets/css/style.css`. It does NOT touch the extraction seam
(`tools/import-post.js`), any `content/**/*.json`, `feed.json`,
`router.js`, `parser.js`, `fetcher.js`, `generate-index.js`,
`hash-state.js`, or `test-integrity.js`. It does NOT make the four new
types reachable from any content file; the seam stays frozen through
D-Tool-29. `footnotes` is listed in the ROADMAP's B1 line but ALREADY
exists in `renderer.js` (C1-tool-seam-footnotes); this milestone VERIFIES
it and does NOT re-add it. `gallery` remains deliberately out of scope
(it is not in the B1 ROADMAP line and has no frozen shape).

## Objective

When this milestone is done, `renderer.js` maps every block type in the
LOCKED_DECISIONS vocabulary EXCEPT `gallery`; all existing block types
render byte-identically (non-regression); the four new types render a
correct, classed DOM for a well-formed block and return `null` (never
throw) for an unusable one; and `style.css` gains only new, additive,
RTL-safe classes that reuse existing tokens.

## Interfaces (mandatory — a milestone without these is not ready)

### Modified: apps/blog/assets/js/renderer.js

    renderBlock(block) gains FOUR cases, inserted before `default:`:

    case "pullquote"
      el: <blockquote class="pullquote">
      body: <div class="pullquote__content"> (innerHTML = block.content)
      cite (only when block.citation truthy):
            <cite class="pullquote__citation">
              (textContent = decodeEntities(block.citation))
      return null if no usable content.
      Input shape (B1-D1): { type:"pullquote",
        content:<plain-text string, tags stripped, entities preserved>,
        citation:<plain-text string|null> }

    case "resourceList"
      el: <ul class="resource-list">
      innerHTML = block.content   (inner HTML of the source list; outer
      tag omitted, mirroring footnotes/list — B1-D2)
      return null if no usable content.
      Input shape (B1-D2): { type:"resourceList", content:<inner HTML> }

    case "callout"
      el: <aside class="callout callout--info">
      inner <div class="callout__content"> (innerHTML = block.content)
      return null if no usable content.
      Input shape (B1-D3): { type:"callout", content:<inner HTML> }

    case "attachment"
      el: <figure class="attachment">
        <a class="attachment__link" href=block.src>
          text = decodeEntities(block.label) (fallback: block.src)
        <figcaption class="attachment__caption"> (only when caption)
          textContent = decodeEntities(block.caption)
      return null if no usable src.
      Input shape (B1-D4): { type:"attachment", src:<url string>,
        caption:<plain-text string|null>,
        label:<plain-text string|null> }

    Injection rule (B1-D6, restates B1a-D1): trusted-markup fields
    (pullquote.content, resourceList.content, callout.content) ->
    innerHTML; plain-text fields (pullquote.citation, attachment.caption,
    attachment.label) -> textContent via decodeEntities(). No user input
    on the render path.

### Modified: apps/blog/assets/css/style.css

    ONE additive "Milestone B1" block, new classes only:
      .pullquote, .pullquote__content, .pullquote__citation
      .callout, .callout--info, .callout__content
      .resource-list
      .attachment, .attachment__link, .attachment__caption
    Reuses existing tokens (--surface, --surface-2, --border, --radius,
    --text, --text-muted, --accent, --transition); logical properties
    only; RTL-safe. Edits NO existing block; adds NO class used by
    another milestone.

## Decisions frozen for this milestone

- B1-D1 pullquote shape: content plain-text (innerHTML), citation
  plain-text|null (textContent via decodeEntities).
- B1-D2 resourceList shape: content = inner HTML of a source list, outer
  tag omitted; rendered `<ul class="resource-list">` innerHTML = content.
- B1-D3 callout shape: content = inner HTML; rendered
  `<aside class="callout callout--info"> > .callout__content`.
- B1-D4 attachment shape: src + caption|null + label|null; rendered
  `<figure class="attachment">` with a link and optional figcaption.
- B1-D5 No seam change. import-post.js untouched; the D-Tool-9 seam stays
  frozen through D-Tool-29. The four shapes are renderer-only and
  defensive.
- B1-D6 Renderer injection rule extended uniformly (restates B1a-D1).
- B1-D7 CSS is additive and new-class-only.
