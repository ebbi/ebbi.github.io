# Milestone 01: Content Fetcher

## Objective

Create the first stage of the offline Node.js build pipeline. This script will fetch raw content from the Pilot WordPress REST API, apply caching, and save the raw data locally. This ensures the build process does not rely on live network requests during development or GitHub Pages deployment.

## Files to Create

1. `zabon/apps/blog/tools/fetcher.js`
2. `zabon/apps/blog/tools/cache/.gitkeep` (Empty file to preserve directory in git)

## Files to Modify

- `zabon/apps/blog/.gitignore` (Add `tools/cache/*.json` to ignore raw cached data)

## Files I will NOT touch

- Any files outside `zabon/apps/blog/`.
- `zabon/apps/blog/assets/` (Frontend files are not touched yet).

## Hard Constraints (from LOCKED_DECISIONS.txt)

- **Node 20 LTS**: Use native `fetch` (no `node-fetch`), native `fs`, and `path`. No external npm dependencies.
- **Pilot URL**: The script must target `https://twolegsbadblog.wordpress.com/wp-json/wp/v2/posts`.
- **Cache-first**: If `tools/cache/raw-posts.json` exists and is less than 24 hours old, skip the network request unless a `--refresh` flag is passed.
- **Error Handling**: Graceful failure if the network is down but cache exists.

## Test Checklist

1. **File Tree Check**:
   - Run: `ls zabon/apps/blog/tools/fetcher.js zabon/apps/blog/tools/cache/.gitkeep`
2. **Gitignore Check**:
   - Run: `grep "tools/cache/*.json" zabon/apps/blog/.gitignore`
3. **Execution Check (No Cache)**:
   - Run from REPO_ROOT: `node zabon/apps/blog/tools/fetcher.js --refresh`
   - It must fetch from the WP API and create `zabon/apps/blog/tools/cache/raw-posts.json`.
4. **Execution Check (Cache Hit)**:
   - Run: `node zabon/apps/blog/tools/fetcher.js`
   - It must output a message indicating it is using the cache and NOT make a network request.
