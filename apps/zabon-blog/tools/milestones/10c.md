# Milestone 10c: List & panel presentation revamp (gate corrections)

## Scope fence (read first)

This milestone implements the HUMAN presentation-review corrections that
landed BEFORE the translation gate was signed off. It changes the LIST VIEW
presentation only, plus ONE explicitly-authorized override of the existing
`.post-detail` class (post view). It SUPERSEDES 10b's per-item collapsible
decision and revisits 08's list presentation.

It is SPLIT OUT from milestone 11 (Translations & i18n UI). The translation
gate is NOT signed off; translations (fa/ar/th) are DEFERRED. 11 does not
run in this chat. This milestone ships NO translation and does NOT change the
language switcher's semantics except as forced by the exclusion list below.

It does NOT touch the extraction seam (`tools/import-post.js`, frozen through
D-Tool-29), `content/**/*.json`, `assets/data/feed.json` (generated),
`assets/js/renderer.js`, `assets/js/router.js`, `tools/{generate-index,
hash-state,test-integrity}.js`, or `tools/{CONTEXT.md,LOCKED_DECISIONS.txt}`.
It does NOT re-touch C1b-18 series ordering (kept verbatim) and does NOT
re-do TTS/TTS2, 07/07b/07c/07d.

## Objective

When this milestone is done, the home/list view shows ALL real blogs wrapped
in ONE collapsible panel titled "Two Legs Bad" (default OPEN), each entry is
just a heading that links to the post (no per-item panel, no date, no
summary text, no "Read full post" link), and three non-blog entries are
excluded entirely from the list. The post view's `.post-detail` width/margin
is adjusted per the human's intentional edit. No EN behaviour outside these
changes regresses; 09's post view (other than `.post-detail` CSS) and B1
block types are unchanged.

## Decisions frozen for this milestone

- D-10c-1 (SUPERSEDES 10b): the per-item collapsible panel is REMOVED. Each
  list item is now a heading that is ITSELF the navigation link; there is no
  per-item aria-expanded/aria-controls and no "Read full post" link.
- D-10c-2: ALL blogs are wrapped in ONE outer collapsible panel titled
  "Two Legs Bad", DEFAULT OPEN, using the same `hidden`-attribute mechanism
  10b used (real <button> + aria-expanded + aria-controls, `hidden` on the
  body). It is the ONLY collapsible on the list view.
- D-10c-3 (EXCLUSION): three non-blog slugs — controlling-the-narrative,
  update, a-contemporary-history-of-the-muslim-world-contents — are excluded
  from the blog set entirely. Mechanism: a hardcoded deny-list in
  renderList() (single source in app.js), because feed.json is generated and
  fenced. Files stay on disk. Display-only exclusion.
- D-10c-4 (D-date=d1): the DATE is dropped from the LIST view only. 09's
  post view keeps `${body.date}` for now; post-view date formatting/removal
  is owned by 11. Also drops the list-view summary text.
- D-10c-5: `.post-detail` is DELIBERATELY overridden (existing-class change,
  explicitly outside 11's additive-only fence) with display:block;
  max-inline-size:720px; margin-inline:1vh 1vw — the human's intentional edit
  for mobile edge-touching (not a typo). All OTHER style.css edits additive,
  new-class-only.
- D-10c-6: the switcher offers ONLY languages that have content (recon: EN
  only). Translations are DEFERRED (gate not signed off); empty fa/ar/th
  recorded as a Known issue, NOT filled with placeholders.
- D-10c-7: C1b-18 series ordering is preserved VERBATIM (partition by integer
  seriesOrder; series 1->N first, then non-series in feed date-desc order).
- D-10c-8: the translation gate is UNSIGNED; this milestone begins NO
  translation work and does not modify the DeepL/Google pipeline.
