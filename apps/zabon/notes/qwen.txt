# Project overview
Zabon is a language agnostic language-learning web app: vanilla HTML/CSS/JS, no frameworks, no build step. 

- `app.js` — the SPA code.
- `index.html` — the app shell.
- `main.css` — the mobile-first design system.
- `manifest.json` — the app registry.
